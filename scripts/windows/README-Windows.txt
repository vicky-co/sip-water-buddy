SIP WATER BUDDY for Windows 10 / 11 (64-bit)
===========================================
A hero and a pet remind you about water, and about anything else you add.

INSTALL (no other software needed)
  1. Right-click the zip > Properties > tick "Unblock" > OK  (if you see that box).
  2. Right-click the zip > Extract All.
  3. Open the extracted folder and double-click Install.bat.
     If Windows says "protected your PC": More info > Run anyway
     (the app is not code-signed, so Windows shows this for any new program).
Sip starts straight away, appears in the Start menu, and starts by itself when you sign in.
You can delete the extracted folder afterwards. Or skip installing and double-click "Sip Water Buddy.exe".

USING IT
  - The water-drop icon is next to the clock (click the ^ arrow if hidden). Double-click it, or right-click it,
    to open Settings. Settings has Characters (names, who shows up, looks), Reminders (water + anything you add,
    with dates and times), Sounds and General.
  - A reminder stays on screen until you answer it: Done, +10 min, +1 hour or Skip.

PRIVACY AND SAFETY
  - Sip never uses the internet (all network requests are blocked) and keeps its data in %APPDATA%\sip-water-buddy.
  - It needs no administrator rights and installs only into your own user folder.

IF SOMETHING LOOKS WRONG
  - Black box instead of a see-through background: run "Start Sip (no GPU).bat".
  - Settings > General > Open log file (also %APPDATA%\sip-water-buddy\sip.log).

REMOVE
  Run Uninstall.bat from the installed copy (%LOCALAPPDATA%\Programs\SipWaterBuddy).
